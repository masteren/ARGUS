# ARGUS リリースノート

## Version 0.5.0

- ソフトウェア名：ARGUS（スマホで操作できる AI 相棒ロボット ＋ Web サービス）
- リリース日：2026年12月8日
- リリースバージョン：0.5.0

### 概要

初回リリースとして、会員登録・ログイン、体験チケットの購入（模擬決済）、チケットを使ったロボットへの指示、購入・取引の記録と管理画面を実装。
ログインからチケットの購入・使用までの流れが、すべてデータベースに記録される。実機ロボットとサーバーの接続は Ver1.0 で公開予定。
ライブ映像・人物を探すミッション・音声対話などは Ver1.0 以降で順に公開予定。

### 目的

- ログイン・購入・チケット使用・記録という、Web サービスとしての中心部分の実現
- 実際に操作してもらい、操作の分かりやすさに関する意見を収集

### リリース内容

#### 新機能

- 会員登録・ログイン機能
  - 名前（24文字まで）と4桁の PIN による新規登録
  - ログイン・ログアウト
  - ログイン中の名前とチケット残高の表示
- 体験チケットの購入機能（模擬決済）
  - 500チケット ¥500〈模擬〉／1,000チケット ¥1,000〈模擬〉の2種類から選択
  - 確認画面で購入を確定すると、残高に加算
  - 「模擬決済・実際の請求はありません」の明記
- ロボットへの指示機能
  - チケット100枚で「前進」「左旋回」「右旋回」を指示
  - 指示はロボットへの命令としてデータベースに登録（実機との接続は Ver1.0）
  - 残高が足りない場合は、操作を受け付けずに不足を表示
- 購入・取引の記録と管理画面
  - 会員・購入・取引・ロボットへの命令を、利用者と時刻付きでデータベースに保存
  - 運営用の管理画面で、売上合計・取引件数・購入履歴・取引履歴を1画面で確認

### 既知の不具合・制限事項

- ロボット本体（Raspberry Pi）の電源が不足気味で、長時間の動作中に再起動することがある
  - 対応予定：Ver1.0までに 5V/5A の電源アダプタへ交換
- 1台のスマホを交代で使う前提のため、60秒操作がないと自動でログアウトする
  - 対応予定：仕様として継続（前の人の残高を次の人に残さないため）
- PIN を忘れた場合の再設定に未対応
  - 対応予定：なし（その場で作って数分だけ使うアカウントのため、対象外とする）
- 会場のローカルネットワーク内でのみ利用可能（インターネットからは使えない）
  - 対応予定：なし（展示会場での利用を前提とするため）

### 技術仕様

- フロントエンド：HTML / CSS / JavaScript
- バックエンド：Python 3 + Flask
- データベース：SQLite
- ロボット：Freenove 6脚ロボット ＋ Raspberry Pi 5（歩行制御は公式プログラムを使用）
- 公開環境：会場ローカルネットワーク（PC 上でサーバを起動）
