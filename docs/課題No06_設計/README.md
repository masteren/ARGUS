## 作り方

3点とも**実際に動いているアプリの画面**から作っている（一時DBで起動し、カメラだけ静止フレームに
差し替えて撮影。AI検出枠はページが `/overlay` を読んで実際に描いたもの。画面に出る名前・残高・
購入履歴は `seed.py` が本番と同じ API を叩いて作ったもの）。

作り直す手順とスクリプトは [ソース/](ソース/) にある。画面のCSSやAPIを変えたら
`bash ソース/build.sh` で作り直すこと（詳細は [ソース/README.md](ソース/README.md)）。

数値・文言はコードと突き合わせて確認済み。主なもの：

- 価格 100 / 300 / 500、アクション6種 … `ARGUS_backend/app.py` の `ACTIONS`
- チケットパック 500チケット ¥500〈模擬〉／1,000チケット ¥1,000〈模擬〉 … `app.py` の `TICKET_PACKS`
